# LG Next 产品定义

## 一句话

LG Next 是一个长期住在本地作品中的通用 Agent。用户主要与它对话；它自行阅读、检索、创作、修改和使用外部模型，作品始终是用户拥有的普通文件。

## 核心体验

1. 用户打开一本书，进入多个可独立延续的对话任务。
2. 用户可以只说“继续”，Agent 自行决定怎样完成创作。
3. 工作过程像 Codex：阶段说明持续出现，工具动作折叠展示，最终结果清楚可查。
4. Agent 直接修改正式作品；每次完整任务都有可恢复版本。
5. 用户通常只阅读、鉴赏，偶尔指出“不对”或修改几个字。
6. 本地便宜模型负责持续工作；需要时准备整包材料供用户复制到官网强模型。

## 产品不做什么

- 不建立 Agent 权限审批流程；
- 不建立固定的续写、铺垫、收线工作流；
- 不把人物、关系、灵性或作品意义做成状态机；
- 不模拟读者应该知道、感受或理解什么；
- 不要求用户维护人物数据库、记忆卡和上下文包；
- 不让摘要替代原文；
- 不把官网会话当作作品记忆。

## 界面重心

### 对话

对话占据主界面。一本书可以有多个任务，每个任务拥有自己的会话历史与运行状态，但共享同一本地作品。

### 工作过程

过程信息分三层：

1. Agent 的简短阶段说明，默认展开；
2. 检索、读取、命令、写入等动作，默认折叠；
3. 原始参数、输出、来源与 revision，用户主动展开后查看。

这不是展示模型的隐藏思维，而是展示可以验证的行动和依据。

### 正文编辑器

底层文件为 Markdown。默认编辑器隐藏不必要的 Markdown 符号，呈现适合中文小说的纸面：

- 舒适行宽和行距；
- 中文段落与标点体验；
- 章节导航、字数和当前位置；
- 专注模式；
- 自动保存与版本恢复；
- 可切换 Markdown 源码模式；
- Agent 改动对比。

## 作品和世界

系统负责保存与访问作品，不负责规定作品最终意味着什么。摘要是地图，索引是导航，正文和用户明确写入的材料才是作品历史。

人物离开视角以后仍可以拥有自己的生活，但系统不需要把这段生活预先模拟完整。Agent 在人物重新出现时回读历史，并创造与其存在相容的新内容。
